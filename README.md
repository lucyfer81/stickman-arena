# stickman-arena

火柴人格斗竞技场游戏。

## 项目结构

```
stickman-arena/
├── index.html        # 入口页面
├── css/              # 样式
├── js/               # 游戏逻辑
├── assets/
│   ├── svg/          # 矢量图形
│   ├── effects/      # 特效
│   └── audio/        # 音频
├── tests/            # 测试
├── notes.md          # 开发笔记
└── README.md
```

## 开发

开发在 `agent-dev` 分支进行，测试通过后合并回 `main`。
